3. 🌳 SourceTree 사용 가이드 (GUI로 쉽게 Git 다루기)
명령어를 외우지 않아도 클릭 몇 번으로 Git을 다룰 수 있게 해주는 편리한 도구인 SourceTree 사용법입니다.

① 내 컴퓨터로 저장소 가져오기 (Clone)
GitHub 레포지토리에서 Code 버튼을 눌러 HTTPS URL을 복사합니다.

SourceTree를 열고 상단의 [Clone/New] (또는 복제/생성) 버튼을 클릭합니다.

'원본 경로/URL' 칸에 복사한 주소를 붙여넣습니다.

'목적지 경로' 칸에 내 컴퓨터의 어느 폴더에 저장할지 지정한 후 [클론(Clone)] 버튼을 누릅니다.

② 변경 사항 저장하고 올리기 (Commit & Push)
내 컴퓨터(로컬)에서 파일을 수정하면 SourceTree의 [파일 상태] 탭에 변경된 파일이 나타납니다.

스테이지에 올리기: 변경된 파일 옆의 + 버튼을 누르거나 [모두 스테이지에 올리기]를 클릭해 커밋할 준비를 합니다.

커밋(Commit): 화면 하단 텍스트 박스에 "무엇을 수정했는지" 알아보기 쉽게 커밋 메시지를 작성하고 [커밋] 버튼을 누릅니다.

푸시(Push): 상단 메뉴의 [Push(푸시)] 버튼을 눌러 GitHub 클라우드에 내 작업물을 업데이트합니다.

③ 최신 버전 받아오기 (Pull)
협업 시 주의사항: 다른 팀원이 코드를 수정했거나, 내가 다른 컴퓨터(또는 코랩)에서 작업한 내용이 있다면, 작업 시작 전 항상 상단 메뉴의 [Pull(풀)] 버튼을 눌러 내 컴퓨터를 최신 상태로 동기화해야 합니다.

④ 브랜치(Branch) 만들고 병합하기
브랜치 생성: 상단의 [브랜치] 버튼을 누르고 새로운 작업 공간의 이름(예: feature-login)을 입력하여 생성합니다.

브랜치 이동(Checkout): 왼쪽 메뉴의 '브랜치' 탭에서 이동하고 싶은 브랜치 이름을 더블 클릭하면 해당 환경으로 넘어갑니다.

병합(Merge):

합치고 싶은 기준 브랜치(보통 main 또는 master)로 먼저 이동(더블 클릭)합니다.

합쳐질 대상 브랜치를 우클릭한 후 [현재 브랜치로 병합(Merge)]을 선택합니다.

⏪ 뒤로 가기 (Reset / Revert)
작업 내역(History) 탭에서 되돌리고 싶은 과거의 커밋 기록을 우클릭합니다.

이 커밋까지 현재 브랜치를 초기화 (Reset): 선택한 시점 이후의 작업을 아예 지우고 싶을 때 사용합니다. (Hard 모드 선택 시 주의)

커밋 되돌리기 (Revert): 선택한 커밋의 변경 사항만 취소하는 새로운 커밋을 만들어 안전하게 덮어씁니다.
